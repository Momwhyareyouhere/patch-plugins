# CPU Monitor

Displays real-time CPU usage per-core in a sidebar panel. Built-in example plugin for Patch.

## Features

- Shows overall CPU usage percentage with color coding (green < 50%, yellow < 80%, red >= 80%)
- Per-core breakdown with animated bars
- Auto-refreshes every 2 seconds
- Customizable sidebar view with CPU icon

## Commands

- `CPU Monitor: Refresh` — manually refresh CPU data

## Usage

Enable the plugin in the Plugins sidebar. A "CPU Monitor" entry appears in the sidebar view selector.
